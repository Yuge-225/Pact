# Screenshot Guide for Figma Make Upload

Take these 5 screenshots from the running app at localhost:3001 using the Demo Panel:

## How to Capture
1. Open the app in Chrome at `http://localhost:3001`
2. Use the Demo Panel (top-right corner) to switch between states
3. Right-click inside the phone frame → "Inspect" → toggle device toolbar for clean captures
4. Or: simply screenshot the phone frame portion of the page
